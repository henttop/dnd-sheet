# Руководство разработчика и Вайбкодинга: D&D 5e Character Sheet

> Полная документация архитектуры, потоков данных, структуры компонентов и инструкция по дальнейшей разработке и вайбкодингу проекта.

---

## 1. О проекте (Overview)

Интерактивный, полностью автономный веб-лист персонажа для **Dungeons & Dragons 5e** (совместим с редакциями 2014 и 2024, правилами SRD 5.1 и 5.2). Современный, быстрый цифровой лист персонажа в стильной тёмной индиго-палитре.

### Главные особенности:
1. **Сборка в 1 автономный файл**: весь проект компилируется в единственный файл `dist/index.html` (HTML + CSS + JS + SVG + встроенная база данных заклинаний). Работает локально в любом браузере двойным кликом без необходимости в веб-сервере или подключении к интернету.
2. **Универсальный формат данных**: поддерживает импорт и экспорт персонажей в структурированном JSON-формате.
3. **Пайплайн бросков кубиков**:
   - Броски проверок характеристик, навыков, спасбросков и атак на к20 с определением критов (20) и провалов (1).
   - Броски урона с **явным указанием бросаемой кости**: например `1к8 (5) + 3 (Сила) колющий` или `2к6 (4+3) + 3 рубящий`.
   - Наложение всех типов заклинаний (урон, лечение, баффы, защита и утилиты).
   - Плавающая дайсница (DiceTower) со свободным набором пула кубиков (d2, d4, d6, d8, d10, d12, d20, d100).
4. **Журнал истории бросков (Roll History)**:
   - Панель выезжает слева экрана по клику на кнопку в шапке или плавающую кнопку внизу.
   - Фильтрация (`Все`, `Атаки`, `Урон`, `Проверки`, `Заклинания`), поиск, кнопка мгновенного повтора броска («Повторить»).
   - Сохранение истории в `localStorage`.
5. **Интеграция с Discord Webhooks**:
   - Отправка результатов бросков в каналы Discord в реальном времени.
   - Информативное форматирование Rich Embeds: имя персонажа в авторе, тип броска в заголовке, подробная формула с костями урона и жирный итог.
   - Проверка связи и управление пресетами каналов в настройках бросков.

## 2. Быстрый запуск и команды сборки

### Использование готового автономного билда:
- Просто откройте файл `dist/index.html` (или `dist/dnd-sheet.html`) в любом браузере. Весь код, стили и шрифты встроены прямо внутрь.

### Команды разработки (Development):
```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (по умолчанию http://localhost:5173)
npm run dev

# Сборка в один автономный HTML-файл (выход в dist/index.html)
npm run build

# Предпросмотр собранного файла
npm run preview
```

## 4. Архитектура и потоки данных (Data Flow)

### 4.1. Хранение персонажей (`src/store.js`)
- Все персонажи хранятся в `localStorage` по ключу `dnd_characters_v2`.
- Если хранилище пусто, автоматически загружается массив из `data/characters.js`.
- Сохранение вызывается функцией `save()`.
- Активный персонаж устанавливается в глобальную переменную `window.__activeChar` при монтировании листа в `Sheet.jsx`.

### 4.2. Глобальный пайплайн бросков (`src/ui.jsx`)

В приложении используется централизованный реестр функций бросков на `window`:

1. **`window.__roll(title, total, mods, opts)`**:
   - Добавляет карточку броска во всплывающую стопку (`push(entry)`).
   - Отправляет бросок в активные Discord вебхуки (`sendRollToWebhooks(entry)`).
   - Записывает бросок в журнал истории бросков (`addRollHistory(entry)`).
2. **`window.__rollD20(title, bonus, mods = "")`**:
   - Генерирует случайное число от 1 до 20 (`d20()`).
   - Добавляет бонус мастерства/характеристики.
   - Определяет критический успех (`d === 20`) или провал (`d === 1`).
   - Вызывает `window.__roll`.
3. **`window.__rollExpr(title, expr, mod, modLabel, extraOpts)`**:
   - Бросок костей урона.
   - Парсит формулу (например, `"1к8"`, `"2d6"`).
   - Формирует строку с **явным указанием кости урона**:
     `${cleanExpr} (${diceBreakdown}) + ${mod} (${modLabel}) ${damageType}`.
   - Вызывает `window.__roll` с флагом `{ isDmg: true }`.
4. **`window.__rollSpell(name, total, dmgType, rolls, extraOpts)`**:
   - Наложение заклинаний всех типов.
   - Сохраняет массив костей `rolls` с формулами `expr`, значениями и типом урона.

### 4.3. Журнал истории бросков (`src/rollHistory.js` & `src/RollHistoryModal.jsx`)

- **Хранилище**: `dnd_roll_history_v1` в `localStorage`.
- **Лимит**: последние 100 бросков (старые автоматически вытесняются).
- **Событие обновления**: кастомный Event `dnd:roll_history_updated` для реактивной синхронизации компонентов без лишних ререндеров.
- **Интерфейс панели**:
  - Расположена слева (`left: 0`, анимация `historySlideLeft`).
  - Фильтры: `Все`, `Атаки`, `Урон`, `Проверки`, `Заклинания`.
  - Полнотекстовый поиск по названию, формуле или имени персонажа.
  - Кнопка **«Повторить»**: повторный бросок с теми же костями и модификаторами.
  - Кнопка **«Очистить»**: очистка журнала с подтверждением.

---

### 4.4. Интеграция вебхуков Discord (`src/webhooks.js`)

- **Хранилище**: `dnd_roll_presets_v1` в `localStorage`.
- **Поддержка**: множественные пресеты каналов Discord с возможностью включения/выключения отдельных вебхуков.
- **Формат сообщений**:
  - `author.name`: имя персонажа (например, *Лелу́ш Ламперу́ж*).
  - `thumbnail.url`: миниатюра портрета персонажа с правой стороны embed-сообщения, автоматически извлекается из `c.data.avatar` (поддерживаются как HTTPS URL, так и локальные base64 через multipart attachment).
  - `title`: тип броска (например, *Бросок урона: Булава*, *Бросок атаки: Длинный меч*, *Заклинание: Огненный шар*).
  - `description`: подробности броска с указанием кубика (например, `1к6 (5) − 1 (Сила) дробящий`), а на последней строке — `Итог: **4**` (или значки `🔥` при крите / `💀` при провале).
  - `color`: настраиваемый цвет пресета (или зелёный `0x40c057` при крите, красный `0xfa5252` при провале).
- **Кнопка проверки**: отправляет тестовый embed *«Всё работает в штатном режиме 👍»* с иконкой персонажа.

### 4.5. Движок формул и переменных в текстовом редакторе (`src/dice.js`, `src/richtext.jsx`, `src/Sheet.jsx`)

В текстовом редакторе заметок, черт характера, предыстории и особенностей классов реализована полноценная система формул и бросков костей:

1. **Интерактивные формулы `[[...]]`**:
   - В режиме чтения формулы отображаются стильными интерактивными фиолетовыми бейджами 🎲.
   - **Всплывающая подсказка при наведении**: вычисляет и показывает предпросмотр подставленных характеристик персонажа (например, `Атака: 1d20 + [STR] → 1d20 + 3 (нажмите для броска)`).
   - **Клик для броска**: мгновенно бросает кости, вычисляет результат, показывает всплывающую карточку, добавляет запись в журнал истории бросков и отправляет результат в Discord-вебхуки.

2. **Переменные характеристик персонажа**:
   - `[STR]`, `[DEX]`, `[CON]`, `[INT]`, `[WIS]`, `[CHA]` — модификаторы характеристик (регистр не важен: `[str]` = `[STR]`).
   - `[PROF]` — бонус мастерства персонажа (`+2`..`+6` в зависимости от уровня).
   - `[HALF_PROF]` — половина бонуса мастерства с округлением вниз.
   - `[LVL]` — уровень персонажа.
   - Поддерживаются вложенные квадратные скобки для динамических формул: `[[[STR]+1]d6]`.

3. **Синтаксис костей и модификаторы**:
   - Базовые кости: `NdS`, `d%` (к100), `dF` (Fate-кубик: -1, 0, +1), русский синтаксис `1к20`, `2к6`.
   - `khN` / `klN` — оставить наибольшие/наименьшие (Keep Highest / Keep Lowest), например `4d6kh3` или `2d20kl1` (помеха).
   - `dhN` / `dlN` — сбросить наибольшие/наименьшие (Drop Highest / Drop Lowest), например `4d6dl1`.
   - `!` / `!>=X` — взрывающиеся кости (Exploding dice), бросающие дополнительный кубик при выпадении максимума или порога.
   - `minN` / `maxN` — минимальное или максимальное значение грани кубика (например `1d20min10`).
   - `ro=X` / `r<X` — переброс кубика один раз (`ro`) или пока выполняется условие (`r`).
   - `cs=X` / `cf=X` — кастомный критический успех (`cs`) или провал (`cf`), например `1d100cs<=25`.

4. **Математические функции и условия**:
   - Базовая арифметика: `+`, `-`, `*`, `/`, `%`, `^` (степень).
   - Функции: `floor()`, `ceil()`, `round()`, `min()`, `max()`, `abs()`, `sqrt()`, `pow()`.
   - Итоговое округление результата вниз по правилам D&D (`Math.floor`).
   - Условия: `if(condition, thenExpr, elseExpr)`, поддерживающие сравнения (`=`, `==`, `!=`, `<>`, `<`, `<=`, `>`, `>=`), логические связки `and`, `or`, `not`, а также вложенные условия `if(...)`.

5. **Извлечение названий и типов урона**:
   - После знака `#`: `1d100cs<=25 # Слишком медленный жест` -> название *"Слишком медленный жест"*.
   - В скобках в конце: `1d20+5 (Атака)` -> название *"Атака"*.
   - Текст перед формулой: `Вдохновение барда 1d6` -> название *"Вдохновение барда"*.
   - Тип урона в конце: `1к6 колющий` -> тип урона *"колющий"*.

6. **Управление в редакторе**:
   - **Горячая клавиша `Ctrl + D`** (и русская `Ctrl + В`):
     - При выделенном тексте оборачивает его в формулу `[[выделенный текст]]`.
     - При курсоре внутри существующей формулы разворачивает её обратно в редактируемый текст.
     - Без выделения вставляет стандартную формулу `[[1d20 + [STR]]]`.
   - Кнопка **«🎲 Бросок»** в боковой панели `InsertBar` и в контекстном меню ПКМ `TextMenu`.
   - **Клик по формуле в режиме правки**: открывает всплывающее окно редактирования формулы с быстрыми кнопками кубиков (+d4..+d100), строкой ввода и кнопкой разворота в текст.
   - Чекбокс **«Формулы активны (Ctrl+D)»** в тулбаре редактора: позволяет временно отключить интерактивные плашки и редактировать все формулы прямо как обычный текст `[[...]]`.

### 4.6. Формулы в числовых показателях персонажа (`src/dice.js`, `src/Sheet.jsx`, `src/helpers.js`)

В полях листа персонажа, где ожидается числовое значение, поддерживается ввод динамических формул:

1. **Класс доспеха (КД / AC)**:
   - В поле «КД (без щита)» можно вводить как числа (`18`), так и любые формулы с переменными:
     - Защита без доспехов варвара: `[dex] + [con] + 10`
     - Защита без доспехов монаха: `[dex] + [wis] + 10`
     - Доспехи мага: `13 + [dex]`
     - Средний доспех с ограничением Ловкости: `14 + min([dex], 2)`
     - Доспех + щит веры: `18 + 2`
   - **Отображение**: на шильдике отображается вычисленное итоговое числовое значение с меткой `ƒ`. При наведении отображается подробная расшифровка формулы с подставленными модификаторами.
   - **Щит (+2 КД)**: флаг щита корректно суммируется с вычисленным базовым КД формулы.

2. **Скорость (Speed)**:
   - Поддерживает формулы вида `30`, `25 + 5`, `if([LVL] >= 5, 40, 30)`.
   - В ячейке скорости отображается вычисленное число, а при инлайн-редактировании доступна исходная формула.

3. **Бонус инициативы (Initiative)**:
   - В поповере инициативы можно задать дополнительный бонус формулой (например, `[WIS]` для Следопыта Сумрачного охотника или Волшебника Военной магии, `[CHA]` для Дуэлянта).

4. **Максимум хитов (Max HP)**:
   - Функция `hp(c)` автоматически вычисляет формулы, если в `v["hp-max"].value` задано выражение вида `10 + [CON]`.

5. **Ресурсы (Resource max & formula)**:
   - В настройках ресурсов поле формулы `formula` поддерживает выражения вида `[PROF]*2`, `[LVL]`, `max(1, [WIS])`, `[LVL] * 5` (Наложение рук).
   - Лимит ресурса автоматически пересчитывается при изменении уровня или характеристик персонажа.
   - В модальном окне ресурса отображается интерактивный предпросмотр результата формулы.

6. **Автодополнение переменных при вводе `[` (`src/FormulaSuggest.jsx`)**:
   - При вводе символа `[` в любом поле формулы (КД, Инициатива, Ресурс, редактирование броска `diePick`) или прямо в текстовом редакторе заметок (`rt-rich`) всплывает список доступных переменных:
     - `[STR]` — Модификатор Силы
     - `[DEX]` — Модификатор Ловкости
     - `[CON]` — Модификатор Телосложения
     - `[INT]` — Модификатор Интеллекта
     - `[WIS]` — Модификатор Мудрости
     - `[CHA]` — Модификатор Харизмы
     - `[PROF]` — Бонус мастерства
     - `[HALF_PROF]` — Половина бонуса мастерства
     - `[LVL]` — Уровень персонажа
     - Именные ресурсы персонажа
   - В каждой строке выводится код, русское описание и текущее значение показателя персонажа (например `+3` или `5`).
   - Поддерживается фильтрация на лету по первым буквам как на латинице, так и на кириллице (`[с` / `[st` → `[STR]`, `[л` / `[de` → `[DEX]`, `[м` / `[pr` → `[PROF]`, `[ур` / `[lv` → `[LVL]`).
   - Навигация клавишами `↑` / `↓`, выбор по `Enter` / `Tab` или клику мыши с автоматическим закрытием скобки `]`, отмена по `Escape`.

### 4.7. Кроссбраузерная совместимость и поддержка Firefox / Waterfox / CORS (`sendDiscordPayload`, `vite.config.js`)
  - В браузерах на движке Gecko (Firefox, Waterfox) строгие политики приватности (Enhanced Tracking Protection), блокировщики (uBlock Origin, Privacy Badger, NoScript) или открытие из `file:///` блокируют прямые cross-site запросы `fetch` к `discord.com` либо вызывают ошибки CORS / preflight.
  - Реализован универсальный многоуровневый механизм доставки:
    1. **Встроенный Vite прокси (`/api/webhook-proxy`)**: при работе на `http://localhost:5173/` запрос передаётся локальному Node.js серверу на том же origin. Node.js выполняет запрос к Discord напрямую через серверный `fetch` без ограничений браузера, CORS или блокировщиков.
    2. **`multipart/form-data` (`FormData`)**: при прямой отправке структура сообщения передаётся в поле `payload_json`, а файл аватарки персонажа — в `files[0]`.
    3. **Нормализация домена**: устаревшие ссылки `discordapp.com` автоматически преобразуются в `discord.com`, предотвращая ошибки CORS при HTTP 301 редиректах.
    4. **Fallback через скрытую HTML-форму (`submitViaHiddenForm`)**: для локального открытия из `file:///` динамически создаётся форма `<form method="POST" enctype="multipart/form-data" target="hidden_iframe">` с отложенной очисткой (5 секунд), отправляющая данные в Discord в обход ограничений браузера.
    5. **Обратная связь в интерфейсе**: при ошибках сети или недоступности вебхука выводится всплывающее уведомление (Toast), а в форме создания/редактирования пресета доступен прямой чекбокс включения активности. Вебхуки работают на 100% стабильно во всех браузерах (Firefox, Waterfox, Chrome, Edge, Safari, Opera).

## 6. Памятка для Вайбкодинга (Vibe-Coding Rules)

Если вы модифицируете проект с помощью нейросетей (Cursor, Windsurf, Claude Code, Gemini, Antigravity):

### 📌 Правило версионирования Git (КРИТИЧЕСКИ ВАЖНО):
> Пользователь требует строгий версионный порядок тегов: **`v0.1`, `v0.2`, `v0.3`, ..., `v0.14`, `v0.15`, `v0.16`** и так далее без пропусков и произвольных названий.
> Перед коммитом всегда проверяйте последний тег через `git tag` и увеличивайте версию ровно на 1:
> ```bash
> git add -A
> git commit -m "v0.15: описание изменений"
> git tag v0.15
> ```

### 📌 Принципы разработки и архитектурные правила:
1. **Автономность билда**:
   - При добавлении любых библиотек убедитесь, что они поддерживают сборку в `vite-plugin-singlefile`.
   - Не используйте внешние CDN-ссылки на стили/шрифты, которые могут отвалиться без интернета. Все ассеты должны инлайниться.
2. **Безопасность данных персонажей**:
   - Никогда не ломайте структуру `data` персонажа: поля `stats`, `skills`, `vitality`, `weaponsList`, `spells` должны сохранять совместимость со схемой персонажа.
   - При добавлении новых свойств используйте безопасный fallback (например: `c.data.myNewField ||= {}`).
3. **Пайплайн бросков**:
   - Любое действие, бросающее кубик, обязано вызывать `window.__roll*` (а не просто `Math.random()`), чтобы бросок попал в UI-карточку, журнал истории и Discord.
   - В бросках урона всегда передавайте формулу кости в `window.__rollExpr(title, expr, mod, modLabel, opts)`.
4. **Терминология D&D на русском языке**:
   - Во вкладке «Личность»: использовать название **«Слабости»** (не «Пороки»).
   - Использовать принятую русскую локализацию: *Спасбросок*, *Бонус мастерства*, *Критический успех/провал*, *Заговор*, *Ячейка заклинания*, *Концентрация*.
5. **Тестирование после изменений**:
   - Всегда запускайте `npm run build` для проверки отсутствия ошибок бандлера и сборки singlefile.
