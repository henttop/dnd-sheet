# D&D 5e Лист персонажа

Самописный интерактивный лист персонажа на **React + Vite**, работающий с файлом
экспорта персонажей в формате JSON. Интерфейс и поведение: кликабельные значения, поповеры,
броски со всплывашкой слева внизу, журнал истории бросков слева и дайсница справа внизу.

## Как запустить

### 1. Автономный запуск (без сервера, 1 файл):
Просто откройте `dist/index.html` (или `dist/dnd-sheet.html`) двойным кликом в любом браузере. Все стили, скрипты и база встроены в один файл.

### 2. Режим разработки:
```bash
npm install        # один раз
npm run dev        # откроется на http://localhost:5173
npm run build      # сборка проекта в единый автономный HTML-файл (dist/index.html)
```

Полная документация по архитектуре, модели данных и вайбкодингу: [DOCUMENTATION.md](file:///C:/Users/henttop/dnd-sheet/DOCUMENTATION.md).

## Данные
- `data/characters.js` — стартовый массив персонажей в формате JSON.
- `data/spells.js` — справочник заклинаний SRD 5.1/5.2 (для расшифровки ID заклинаний).
- `data/characters.json` — исходный файл экспорта (на всякий случай).

## Что умеет
- Список персонажей с аватарами и HP; drag&drop / кнопка `.json` для загрузки другого экспорта.
- **Кнопка «+»** под сеткой — создаёт пустого персонажа (всё по нулям: КД —, скорость 0, HP 0/0,
  характеристики 10, навыки +0) и открывает его лист. Показывается модалка «Создание персонажа»
  с кнопкой «Заполнить самостоятельно» — после неё лист заполняется руками (клик по любому значению).
- **Меню «⋯» на карточке**: Копировать / Скачать .json / Удалить (как на сайте).
- **Меню под аватаром** (ЛКМ по портрету): Настройки / Сменить портрет (+ Поделиться, Комната,
  Классический лист, Гримур — пока недоступны, как и на сайте без подписки).
- **Панель «Настройки»**: имя, раса, класс, подкласс, КД, инициатива (со своим бонусом), скорость
  (со своим бонусом), редакция правил (2014/2024), перевод, бонус мастерства (свой или авто по уровню),
  уровень и опыт, а также разделы «Конструктор персонажа», «Настройки бросков», «Настройки заклинаний»,
  «Настройки класса», «База знаний».
- **Панель «Сменить портрет»**: загрузка файла (до 3 МБ, jpg/png/webp) или по ссылке, удаление портрета.
- Шапка: портрет (клик — сменить по ссылке или файлом), имя, раса/класс/подкласс — всё редактируется кликом.
- Уровень и опыт: клик по чипу уровня или полоске опыта — правка.
- КД (клик — правка КД и флажок щита), скорость, бонус владения.
- HP: клик по плашке хитов открывает **модалку здоровья**
  (`?modal=health`): панель слева, крупный «текущее/максимум», поле ввода,
  цифровая клавиатура (7 8 9 / 4 5 6 / 1 2 3 / 0, `+`/`−`, стереть) и действия
  **ВРЕМЕННЫЕ / ЛЕЧЕНИЕ / УРОН**, счётчик, кнопка настроек (⚙).
  - **УРОН** сначала съедает временные хиты, потом основные (как в правилах).
  - Четыре зелья лечения — как на dnd.su (5e24): Зелье лечения 2к4+2,
    Зелье большого лечения 4к4+4, Зелье отличного лечения 8к4+8,
    Зелье превосходного лечения 10к4+20 (от меньшего к большему).
  - ⚙ — настройки (макс. HP, темп. HP, короткий и длинный отдых).
- Монеты (клик по золоту): ПМ/ЗМ/ЭМ/СМ/ММ, итого считается автоматически.
- HP (клик — поповер с −5/−1/число/+1/+5, темп. HP, короткий/длинный отдых) —
  заменено модалкой здоровья (см. ниже).
- Инициатива (клик — бросок, правый клик — свой бонус), вдохновение (клик — вкл/выкл),
  истощение (клик — +1 ступень, правый клик — сброс), эффекты и состояния (клик — список).
- Характеристики: клик по счётчику — правка; «Проверка» и «Спасбросок» — броски;
  кружок у «Спасбросок» — владение (Нет/Владение).
- Навыки: кружок или название — поповер (Нет / Владение / Экспертиза + своё значение),
  кнопка с бонусом — бросок к20.
- Пассивные чувства, владение доспехами/оружием (чипы переключаются кликом), прочие владения и языки.
- Вкладки: Атаки (таблица, всё редактируется, + добавить / − удалить, броски атаки и урона),
  Способности, Снаряжение (грузоподъёмность и размер считаются), Личность, Цели, Заметки —
  rich-text блоки (правка по кнопке или клику; «- » = список, «——» = разделитель).
- Спойлер в rich-text вставляется как отдельный блок, перед и после него всегда
  стоят пустые защитные строки (их нельзя удалить — иначе «ломается» поле):
  в них можно печатать, но строка останется на месте.
- Ресурс в тексте — фиолетовая «таблетка» во всю строку:
  `📦 название − N/M +`. Вне режима правки настройки ресурса не открываются
  (клик по плашке ничего не делает), но счётчик ± работает. В режиме правки
  клик открывает настройки, × убирает ресурс из текста; удалить сам ресурс
  можно в его настройках (кнопка «Удалить»).
- В листе (без режима правки) спойлер тоже управляется: `×` — оставить только
  текст, `🗑` — удалить блок вместе с текстом. Кнопки различаются цветом:
  × — золотой, 🗑 — красный.
- Заклинания: Сл спасброска/атака/характеристика считаются автоматически, ячейки (клик —
  потратить/вернуть, число ячеек правится), заклинания из prepared/book; то, чего нет в
  справочнике, помечается «Заклинание (нет в справочнике)».
- Дайсница (фиолетовый кубик справа внизу): набор пула к2–к100, −/×, бросок.
- Все правки сохраняются в браузере (localStorage) и попадают в экспорт
  (`.json → Скачать .json` выгружает обновлённый файл).

## Горячие клавиши в полях
`Enter` — сохранить, `Esc` — отмена.

## Правила (сверено с dnd.su / PHB)
- Модификатор характеристики: `(значение − 10) / 2` с округлением вниз.
- **Бонус мастерства зависит от уровня**: 1–4 → +2, 5–8 → +3, 9–12 → +4, 13–16 → +5, 17–20 → +6
  (можно переопределить вручную в «Настройках»; 0 = считать автоматически).
- Проверка характеристики: к20 + модификатор (без бонуса мастерства).
- Спасбросок: к20 + модификатор + бонус мастерства (если есть владение).
- Навык: к20 + модификатор + бонус мастерства (×2 за экспертизу); своё значение полностью заменяет бонус.
- Пассивное значение: 10 + все применимые модификаторы (в т.ч. бонус мастерства за владение навыком).
- Сложность спасброска заклинания: 8 + модификатор заклинательной характеристики + бонус мастерства.
- Атака заклинанием: к20 + бонус мастерства + модификатор заклинательной характеристики.
- Инициатива: к20 + модификатор Ловкости (+ свой бонус).
- КД без доспеха: 10 + модификатор Ловкости (в листе КД — число, щит даёт +2).
- Монеты: 1 пм = 10 зм, 1 эм = 0.5 зм, 1 см = 0.1 зм, 1 мм = 0.01 зм.
- Грузоподъёмность: СИЛ × 15 фунтов; толкать/тащить/поднимать — СИЛ × 30.
- Короткий отдых: трата одной кости хитов (1к10 + ТЕЛ); длинный отдых: все хиты, сброс темп. HP, −1 истощение.
- Истощение: 6 ступеней; вдохновение — 1 за длинный отдых.
- Уровни и опыт: 0 / 300 / 900 / 2700 / 6500 / 14000 / 23000 / 34000 / 48000 / 64000 / 85000 /
  100000 / 120000 / 140000 / 165000 / 195000 / 225000 / 265000 / 305000 / 355000.

- Синхронизация с сервером — всё локально.
